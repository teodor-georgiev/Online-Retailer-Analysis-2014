# DMC 2014 Clean-Room Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a standalone, leakage-safe Python benchmark and research pipeline for DMC 2014 from the raw ZIP files only.

**Architecture:** The package separates raw-data access, scoring, temporal splits, features, models, experiment orchestration, and the CLI. Normal training/backtest code cannot import April labels; final evaluation uses a separate explicit loader and command. All target-history features are shifted or fit only on earlier labeled history.

**Tech Stack:** Python 3.11+, pandas, numpy, scikit-learn, CatBoost, LightGBM, pytest.

**Spec:** `docs/superpowers/specs/2026-09-16-dmc2014-clean-room-design.md`

## Global Constraints

- Use only raw files from `Orders_data/Orders_train_test_class.zip`.
- Do not import notebooks, processed CSVs, or `Model_functions.py`.
- April labels must not be reachable from normal backtest/model-selection functions.
- Validation folds are January, February, and March 2013, trained only on earlier labeled rows.
- Target-history validation features use only labels strictly before the validation month.
- Training target-history features exclude each row's own target and future targets.
- Do not modify `master`, merge, deploy, or commit generated datasets/models/results.
